Three reasons this fails — every time

1. Diffs are impossible. Try to figure out what changed between project-v2 and project-v2-FIXED. The folders are identical except for one line in one file — and there's no way to know without manually opening every file.
2. Storage doubles per version. 100MB × 8 versions = 800MB on disk, of which 99% is duplicates. Git stores the same history in roughly 105MB by sharing unchanged content.
3. Two people can't safely edit at once. If Alice and Bob both start from project-final, they'll each produce a divergent v2. Merging by hand is impossible past about three files.
