Two ways to model history

Same 5 commits, two storage strategies. The Git way stores complete file states; the older way stores incremental diffs.

RCS-style — diff against previous


        
To reconstruct any commit, you must replay ALL diffs from the start. Jumping to commit-3 means applying commits 1, 2, 3 in order.

      

      

        
Git-style — full snapshot

        

        
Each commit is the complete file. Jumping to commit-3 is a single read. Unchanged files share storage with previous commits internally.
