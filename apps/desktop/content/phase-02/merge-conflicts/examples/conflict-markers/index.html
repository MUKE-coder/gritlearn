Three regions in this one file. Each <<<<<<< … >>>>>>> set is independent — resolve them one at a time. They don't have to be resolved the same way.

The five resolution strategies

StrategyWhat to keepWhen to use
Keep yours The lines between <<<<<<< HEAD and ======= You're confident the current branch's version wins.
Keep theirs The lines between ======= and >>>>>>> The incoming branch did the right thing.
Keep both All lines between the markers — but delete the markers Both versions are valid additions (e.g. two new imports).
Combine Write a third version that incorporates both intents Most "real" resolutions. Read both, decide a synthesis.
Ask (no edit yet) Genuinely unclear — Slack the author of the conflicting commit.
