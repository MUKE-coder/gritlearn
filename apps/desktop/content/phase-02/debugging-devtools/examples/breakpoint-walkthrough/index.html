Buggy discount — find it with the debugger

This page calculates an order total. The 10% discount is supposed to apply only on orders over $1,000 — but it's firing for almost every order. Open devtools, set breakpoints at the marked lines, and use the Scope panel to find the bug.

The function — three candidate breakpoint lines:

function checkout(items) {
  const subtotal = items.reduce(            // ① breakpoint here — what's `subtotal`?
    (s, i) => s + i.priceCents * i.qty, 0
  );

  let discount = 0;
  if (subtotal > 1000) {                    // ② breakpoint — compare what to what?
    discount = Math.round(subtotal * 0.10);
  }

  const final = subtotal - discount;        // ③ breakpoint — final values
  return { subtotal, discount, final };
}
Hint: Set the breakpoint on line ②. Look at the Scope panel — what is subtotal? Now look at the literal 1000 in the comparison. Are they in the same unit? Right-click the value in the Scope panel → Modify value to confirm what the fix would do.
