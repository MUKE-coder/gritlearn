Circular imports → silent undefined

The trap

// a.js
import { fromB } from "./b.js";
export const fromA = "A";
console.log("a.js sees fromB =", fromB);

// b.js
import { fromA } from "./a.js";
export const fromB = "B";
console.log("b.js sees fromA =", fromA);

// main.js → import "./a.js"

The fix — extract the shared bit

// shared.js
export const fromA = "A";
export const fromB = "B";

// a.js  → import { fromA, fromB } from "./shared.js";
// b.js  → import { fromA, fromB } from "./shared.js";  // no cycle
