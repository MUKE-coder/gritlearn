Same dot, two outcomes

Both methods read this.name. The regular function sees user; the arrow always sees the outer scope.

Regular method — function () { ... }

const user = {
  name: "Ada",
  greet: function () {
    return "Hi, " + this.name;
  }
};
user.greet();
…

Arrow method — ignores the dot

const user = {
  name: "Ada",
  greetArrow: () => {
    return "Hi, " + this.name;
  }
};
user.greetArrow();
…

Arrows inherit this from where they were defined, not from where they're called. At the module top level here, the outer this is the global object — which has no name field, so the read is undefined.
