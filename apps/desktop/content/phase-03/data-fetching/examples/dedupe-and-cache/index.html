How dedup works

During a single render pass, Next.js uses React's cache() helper (or wraps your fetch) to memoize identical calls. Multiple components calling the same function (with the same args) inside the same render only execute once.

import { cache } from "react";

export const getCurrentUser = cache(async () => {
  // runs once per render, even if called 5 times
  return db.user.findUnique({ where: { id: await getSessionId() } });
});
