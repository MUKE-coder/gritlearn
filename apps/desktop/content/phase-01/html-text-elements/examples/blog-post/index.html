Why I learned to code in a basement

Published March 2026

I'm writing this to remember what it felt like before any of it clicked. I want the version of me from six months ago to read this and feel less alone.

The first month

I started with a free YouTube playlist and an empty editor. Three weeks in, I had built nothing. The videos kept saying "in the next section, we'll build a real app" — but the next section never came.

What changed

I switched to a curriculum that opened every lesson with an analogy. Closures were a backpack a function carries. The DOM was a remote control for the page. Suddenly the words had hooks I could hang things on.

The three things I'd tell anyone starting over

  • Find a curriculum where the lessons connect to each other.
  • Type the code yourself. Don't copy-paste from the example.
  • Build something terrible by the end of week one. Then iterate.

A workflow that finally stuck

  1. Read one concept page.
  2. Open the example project and run it.
  3. Change one thing and predict what happens — then check.
  4. Move on.

"You'll never feel like you know enough to start. Start anyway."

If you're reading this and you're three weeks in and feel stuck — that's the cliff right before the climb. Keep going.
