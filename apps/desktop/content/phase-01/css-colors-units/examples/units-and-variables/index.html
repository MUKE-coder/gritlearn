px vs rem vs % vs vh

Resize the window and watch the four boxes below. Only some of them respond. In your browser's settings, change the default font size from 16px to 20px — the rem box grows; the px box doesn't.

width: 200px

Fixed pixels. Stable, but doesn't respect user font-size.

Use when you want an exact dimension that never moves.

width: 16rem

Scales with the root font size. The modern default for spacing.

Use for font sizes, padding, margins — anything you want to scale.

width: 50%

Half the card. Resizes with the parent.

Use for "fill the parent" behavior.

height: 15vh

15% of the viewport height. Resize the window vertically.

Use for full-bleed hero sections and modal overlays.

Try this: change --accent at the top of the <style> block from #4763e4 to #dc2626. Every accent on the page turns red — without touching any of the individual rules. That's the variable superpower.
