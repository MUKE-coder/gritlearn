Three rules walk into a bar

The same paragraph below has three CSS rules trying to color it. Specificity decides which one wins.

p → (0,0,0,1) color: red .lead → (0,0,1,0) color: blue #fightTarget → (0,1,0,0) color: green
Round 1 — tag only. red wins by default.

I want to be styled.

Round 2 — add the class .winner-by-class → blue wins.

I want to be styled.

Round 3 — add a more specific id rule (#fightTarget.winner-by-id) → green wins.

I want to be styled.

Round 4 — add an inline style. Inline always wins (without !important).

I want to be styled.

Open DevTools → click each paragraph → look at the Styles panel. The browser shows every rule and crosses out the losers.
