Promise.all vs serial awaits

Both panes run three "fetches" that each take 1 second. Watch the total elapsed time.

serial awaits

const a = await wait(1000);
const b = await wait(1000);
const c = await wait(1000);
// total ≈ 3000ms
—

Promise.all

const [a, b, c] = await Promise.all([
  wait(1000),
  wait(1000),
  wait(1000),
]);
// total ≈ 1000ms
—
