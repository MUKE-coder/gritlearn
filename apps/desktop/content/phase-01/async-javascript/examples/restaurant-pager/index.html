Same task, three styles

Each pane "fetches" a fake user (300ms timeout). The result is the same; the syntax is what changes.

1. callback

fetchCb((err, user) => {
  if (err) showErr(err);
  else show(user);
});
—

2. .then chain

fetchP()
  .then(show)
  .catch(showErr);
—

3. async / await

try {
  const user = await fetchP();
  show(user);
} catch (e) {
  showErr(e);
}
—
