content-box vs border-box

Both cards declare width: 300px; padding: 20px; border: 4px solid;. Only the box-sizing differs. The grey ruler above each card is exactly 300px wide so you can see the difference.

box-sizing: content-box (default)

Renders at 348px — width 300 + left/right padding (40) + left/right border (8).
Card is wider than the 300px ruler.

box-sizing: border-box (recommended)

Renders at exactly 300px — padding and border are subtracted from the width.
Card fits inside the 300px ruler.

Set * { box-sizing: border-box; } at the top of every stylesheet you write. Every CSS framework already does this — it's the single most useful one-liner in CSS.
