Four loops, one task

All four print the array [10, 20, 30, 40, 50] one item at a time. Same result; different syntax.

1. classic for indexed

for (let i = 0; i < arr.length; i++) {
  log(arr[i]);
}

2. for…of modern default

for (const n of arr) {
  log(n);
}

3. while

let i = 0;
while (i < arr.length) {
  log(arr[i]);
  i++;
}

4. forEach

arr.forEach((n) => {
  log(n);
});

In modern code, for…of and forEach/map/filter cover 95% of needs. Reach for the classic indexed for only when you need the index or unusual increments.
