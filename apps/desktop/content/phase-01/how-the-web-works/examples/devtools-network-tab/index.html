See it for yourself 2 min

Looking at requests is the single most underrated skill in web dev. Once you can read the Network tab, half of all "why is this broken?" stops being a mystery.

  1. Open this page's DevTools: F12 (Windows / Linux) or ⌘⌥I (Mac).
  2. Click the Network tab at the top of DevTools.
  3. Press Ctrl/⌘ + R to reload this page.
  4. Watch the list fill. The first row is the HTML you're reading; below it are the rows for every image, font, and script the browser fetched because of that HTML.
  5. Click any row → look at the Headers, Response, and Timing sub-tabs.

Notice the four-beat dance is laid bare here: Headers shows the request, Response shows what came back, and Timing shows how long each step took. Same pattern, every request, forever.
