Three syntaxes, same function

All three return the same string. They differ in hoisting and this behavior.

declaration

function greet(name) {
  return `Hello, ${name}!`;
}
greet("Aisha") →

expression

const greet =
  function(name) {
    return `Hello, ${name}!`;
  };
greet("Brian") →

arrow (modern)

const greet = (name) =>
  `Hello, ${name}!`;
greet("Carla") →

Hoisting

The declaration is hoisted; the others aren't.

// works — function declarations are hoisted to the top of their scope:
beforeDeclaration();
function beforeDeclaration() { console.log("ran"); }

// throws — const/let are not hoisted with their values:
beforeArrow();
const beforeArrow = () => console.log("ran");
// ReferenceError: Cannot access 'beforeArrow' before initialization
Modern advice: use arrows by default. Reach for function only when you need its this behavior (rare) or hoisting (also rare).
