Pure vs side effects

Both functions "add 1 to a counter." One is pure (no mutation), one mutates a shared variable. Click the buttons and watch the difference.

✓ Pure — returns new value
function increment(n) {
  return n + 1;       // takes n, returns n+1
}                       // no globals, no DOM, no mutation

Counter (kept in component state):

0

The function takes a number and returns a number. The caller decides what to do with it (assign it to a variable, render it, ignore it).

⚠ Impure — mutates a shared variable
let count = 0;
function bump() {
  count++;            // reaches into outer scope
}                       // side effect — no return

Shared count:

0

Both buttons call bump() and read the same shared count. Calls from different places fight over the same state.

Lesson: the pure version is local — its behavior depends only on its inputs. The impure version is global — any change to count happens everywhere at once. In a small example that's fine; in a real app it's the source of weeks of debugging.
