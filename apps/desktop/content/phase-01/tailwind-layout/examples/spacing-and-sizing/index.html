The Tailwind spacing scale

The number in any spacing class is multiplied by 0.25rem. p-4 = 1rem = 16px at the default root font size.

padding (p-1 → p-16)

The blue line inside each bar shows where the content lives. The bigger the padding, the more breathing room.

p-1 · 4px
p-2 · 8px
p-4 · 16px (the everyday default)
p-6 · 24px
p-8 · 32px
p-12 · 48px
p-16 · 64px

gap (gap-0 → gap-8)

Same scale, applied to gap in a flex/grid container.

ABCgap-0
ABCgap-2
ABCgap-4
ABCgap-8

max-width (named, not numeric)

For max-width, Tailwind uses named t-shirt sizes. These are the most common.

max-w-xs · 20rem (320px)
max-w-sm · 24rem (384px)
max-w-md · 28rem (448px)
max-w-lg · 32rem (512px)
max-w-2xl · 42rem (672px) — common for blog posts
max-w-4xl · 56rem (896px)
max-w-6xl · 72rem (1152px) — common for marketing pages
