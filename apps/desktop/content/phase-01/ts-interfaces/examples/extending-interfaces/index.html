Greeting any kind of Person

Every card below is a different extension of Person: Employee adds department; Customer adds plan. The greeting function only knows about Person — but because both extensions still are Persons, the function works for all of them. That's the win of extension: write the consumer once. 

type Person = { name: string };

// Two extensions — pick either syntax.
type Employee = Person & { kind: "employee"; department: string };
type Customer = Person & { kind: "customer"; plan: "free" | "pro" };

function greet(p: Person): string {
  return "Hello, " + p.name;
}
