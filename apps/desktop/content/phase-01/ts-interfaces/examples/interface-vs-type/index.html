The same shape, two ways

Below: type on the left, interface on the right. The everyday cases are interchangeable; the two cells at the bottom show where they diverge.

Declaring an object shape

type User = {
  id:    number;
  name:  string;
  email: string;
};

interface User {
  id:    number;
  name:  string;
  email: string;
}

Extending

type Employee = User & {
  department: string;
  salary:     number;
};

interface Employee extends User {
  department: string;
  salary:     number;
}

Only type can do this — unions

type Mode   = "dark" | "light";
type Result = User | null;

// interface can't be a union.
// Use type instead.

Only interface can do this — declaration merging

// type with same name = duplicate error.
type Box = { a: number };
type Box = { b: string };   // ✗ Duplicate identifier

interface Box { a: number }
interface Box { b: string }
// ✓ Box now has both a and b.
