The same counter, two approaches

Both panes show a button + count. The vanilla version manually keeps the DOM in sync. The React version describes the UI for any given state and lets React handle the DOM.

vanilla DOM

let count = 0;
const span = document.querySelector("#vCount");
document.querySelector("#vInc")
  .addEventListener("click", () => {
    count++;
    span.textContent = count;  // ← manual update
  });
0

React (useState)

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div className="counter">
      <button onClick={() => setCount(count + 1)}>+1</button>
      <span>{count}</span>
    </div>
  );
}

The React version doesn't reach for the DOM — it describes what to render based on the current count. The framework handles the diff.
