Three ways to attach CSS

All three paragraphs below end up with the same look (blue + bold). The difference is where the rule lives.

1. Inline (style attribute)

The style lives on this element. Hard to reuse — paste it on every paragraph that needs it.

The style lives in a <style> block in <head>. Reusable on this page only.

The style would live in a separate styles.css file. Reusable across every page that links to it. The browser caches the file. This is what every real project uses.
