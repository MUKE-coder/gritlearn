Pointer vs value — same function, very different result

A function called rename(u, "Beth"). On the left, the parameter is a value. On the right, a pointer. Hit Run on each side and compare what the caller sees afterwards.

1. Value receiver

func rename(u User, name string) {
    u.Name = name   // mutates the COPY
}

u := User{Name: "Ava"}
rename(u, "Beth")
fmt.Println(u.Name)

2. Pointer receiver

func rename(u *User, name string) {
    u.Name = name   // mutates through the pointer
}

u := User{Name: "Ava"}
rename(&u, "Beth")
fmt.Println(u.Name)
